# tplink-hb810-mcp

Bu yerel MCP sunucusu **TP-Link Aginet HB810** için geliştirildi. Bağlı cihazları, Wi-Fi durumunu, DHCP kayıtlarını ve sistem günlüklerini bir MCP istemcisinden inceleyebilirsiniz.

Sunucu Node.js 22.19 veya üzerini kullanır. Mevcut modem sürücüleri, uv ile başlatılan bir Python bağdaştırıcısıyla çalışır.

[Kurulum ve HB810 yapılandırması](README.md#quick-start) · [HB810 yönetim menüsü ve MCP araçları](docs/hb810-admin-menu.md)

Bu proje, [Yakup Emre Yerli](https://github.com/YakupEmreYerli) tarafından oluşturulan [tplink-modem-mcp](https://github.com/YakupEmreYerli/tplink-modem-mcp) projesinin bir çatalıdır. Özgün projenin [Türkçe belgeleri](https://github.com/YakupEmreYerli/tplink-modem-mcp/blob/main/README.tr.md) kendi deposunda bulunur.
